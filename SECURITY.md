# Security

If you find a vulnerability in the Meridiaan service, its MCP server, or anything in this repository, please do not open a public issue.

Write to **support@meridiaan.io** with the subject line **Security**, and include:

- what you found and where (address, tool, page);
- the steps to reproduce it;
- what an attacker could do with it.

We will confirm receipt within three working days, keep you updated while we fix it, and credit you if you wish once the fix is out.

If you shared a Workspace token by mistake (in a repository, a screenshot, an install link), rotate it from the Connection page of that Workspace: the old one stops working immediately.
