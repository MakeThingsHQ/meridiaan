# Getting help

| You want to | Go to |
|---|---|
| Ask how to do something, share a setup, propose an idea | [Discussions](../../discussions) |
| Report something broken | [Issues: bug report](../../issues/new?template=bug_report.yml) |
| Say whether a client configuration worked | [Issues: client report](../../issues/new?template=client_report.yml) |
| Sort out your account, plan or invoice | support@meridiaan.io |
| Report a vulnerability | [SECURITY.md](SECURITY.md) |

The documentation at [docs.meridiaan.io](https://docs.meridiaan.io) answers most questions about concepts, roles and plans. Your agent can read it too: point it at `https://docs.meridiaan.io/llms-full.txt`.
