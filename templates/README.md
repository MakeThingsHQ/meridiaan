# Workspace templates

A template is a structure for a Workspace: which Collections to open, which statuses each one has, and the instructions every agent writing there will receive. There is nothing to import: you hand the template to your agent and it builds the Workspace with the tools it already has.

## How to use one

1. Create an empty Workspace and connect your agent as **Owner** (only the Owner can shape a Workspace).
2. Open the template, copy the block under **Setup prompt**, paste it to your agent.
3. The agent checks the Collection types available, opens each Collection, and writes its instructions. Review the result in the web app and change anything that does not fit.

Adapt freely. A template is a starting point, and a Workspace that stays loosely structured is a valid choice too.
